# 软考备考资料库（三科目 · 30 天体系）

面向三项软考高级资格的完整备考资料库：**信息系统项目管理师**、**系统架构设计师**、**系统规划与管理师**。每科目按"00-备考总计划.md"编排 Day01-30 共 30 天完整备考周期，全部内容基于各科官方教程（第4版）知识体系编写。

## 目录结构

```
Exam/
├── README.md                          # 本文件
├── 备考学习预览器.html                  # 阅读与练习一体的本地工具
├── 00-三科目论文背景行业清单.md         # 论文背景行业占用登记（单一事实源）
├── 信息系统项目管理师/                  # 高项：Day01-30
│   ├── 00-备考总计划.md
│   └── Day01 ~ Day30/
├── 系统架构设计师/                      # 架构师：Day01-30
│   ├── 00-备考总计划.md
│   └── Day01 ~ Day30/
└── 系统规划与管理师/                    # 系规管：Day01-30
    ├── 00-备考总计划.md
    └── Day01 ~ Day30/
```

## 每日五件套（普通教学日标准结构）

| 文件 | 内容 |
|------|------|
| `01-真题考点精讲.md` | 当日主题考点精讲（考点→考法→速记体例），结尾附自查清单 |
| `02-模拟卷-综合知识-试题.md` | 75 道单选题：当日主题约半数 + 往期滚动复习 + 专业英语 5 题 |
| `03-模拟卷-综合知识-答案与解析.md` | 15 行×5 列答案速查表 + 逐题解析（`**N. X**【考点】` 判分行）+ 考点分布自评表 |
| `04-模拟卷-案例分析-试题与参考答案.md` | 案例分析题（高项/系规管 3 题；架构师 5 选 3、第 1 题必做），必含计算题，评分点标注分值 |
| `05-模拟卷-论文-题目与写作指导.md` | 2 题选 1，每题含三问仿真格式、写作指导、2500 字级完整范文（结尾含"不足与体会"段） |

特化日（全真模拟日、计算/找茬/论文专项日、考前收官日等）的文件名与结构按当日定位调整，如 `01-全真模拟一-期中复盘指南.md`。

## 使用方式

**用浏览器打开 `备考学习预览器.html` 即可开始**（本地文件直接双击打开）：

- 左侧目录树选择科目与 Day，右侧渲染阅读；
- **练习模式**：打开 `02-模拟卷` 自动进入——点选项作答、交卷判分、只看错题、一键复制错题摘要；
- **得分统计**：交卷后打开 `03-答案与解析` 自动显示得分横幅（得分/用时/及格判定），并将文件内自评表的"你的得分"列填充为按篇章统计的真实得分（数据存本机浏览器，不做任何上传）；
- 学习记录、高亮批注、任务清单等由预览器本地管理。

## 质量标准（全库 90 卷程序化验证达标）

- **判分行**：每卷 75 条、题号 1-75 连续——预览器自动判分依据；
- **答案速查表**：竖排 15 行×5 列，与逐题解析逐格零不一致；
- **答案分布**：A/B/C/D 各约 18-19，均衡防"背位置"；
- **计算题数字**：EVM/PERT/CPM/决策树/CBAM/可用度/Amdahl 等全部经独立复算自洽；
- **论文行业多样性**：高项与架构师 120 篇范文使用 96 个零重复行业背景，占用情况登记于《00-三科目论文背景行业清单.md》。

## 备考节奏建议

按各科 `00-备考总计划.md` 的日程推进：精讲（早）→ 限时做 75 题（午）→ 交卷判分 → 案例与论文（晚）；全真模拟日（如 Day15/21/25）严格计时三科连做；收官周（Day26-30）以热身卷、背诵卡与错题归因复盘为主。
