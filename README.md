# 软考三科目题库与训练资料库

面向三项软考高级资格的**可持续训练题库**：**信息系统项目管理师**、**系统架构设计师**、**系统规划与管理师**。每科目按知识体系编排 Day01-30 共 30 天完整内容，全部内容基于各科官方教程知识体系编写，用于长期刷题训练、错题归因与论文素材积累，适合个人反复使用与分享传播。

## 每日五件套（普通日标准结构）

| 文件 | 内容 |
|------|------|
| `01-真题考点精讲.md` | 当日主题考点精讲（考点→考法→速记体例），结尾附自查清单 |
| `02-模拟卷-综合知识-试题.md` | 75 道单选题：当日主题约半数 + 往期滚动复习 + 专业英语 5 题 |
| `03-模拟卷-综合知识-答案与解析.md` | 15 行×5 列答案速查表 + 逐题解析（`**N. X**【考点】` 判分行）+ 考点分布自评表 |
| `04-模拟卷-案例分析-试题与参考答案.md` | 案例大题（高项/系规管 3 题；架构师 5 选 3、第 1 题必做），必含计算题，评分点标注分值 |
| `05-模拟卷-论文-题目与写作指导.md` | 2 题选 1，每题含三问仿真格式、写作指导、2500 字级完整范文 |

特化日（全真模拟、计算/找茬/论文专项、错题复盘、考前收官等）的文件名与结构按当日定位调整，如 `01-全真模拟一-期中复盘指南.md`、`01-考前最终检验指南.md`。

## 使用方式

**用浏览器打开 `备考学习预览器.html` 即可开始**（本地文件直接双击打开，无需任何服务端）：

- 左侧目录树选择科目与 Day，右侧渲染阅读；
- **练习模式**：打开 `02-模拟卷` 自动进入——点选项作答、交卷判分、只看错题、一键复制错题摘要；
- **得分统计**：交卷后打开 `03-答案与解析` 自动显示得分横幅（得分/用时/及格判定），并把文件内自评表的"你的得分"列填充为按篇章统计的真实得分；
- 学习记录、高亮批注、任务清单均由预览器本地管理（存于本机浏览器，不上传任何数据）。

## 训练建议（题库视角）

- **日常刷题**：按科目 README 的 30 天知识地图选择当日主题卷，也可跨 Day 随机组合刷题；
- **错题归因**：预览器练习模式交卷后按"考点标签"回读对应日的精讲，各科的错题复盘卷（高项 Day27、架构师 Day29、系规管 Day14/24）提供高频错点变形再考；
- **计算专精**：三科的计算公式卡（高项 Day10/19/29、架构师 Day29、系规管 Day20/26）配合各卷计算大题反复演算；
- **论文训练**：先读各科论文专项日的结构解剖方法，再用法"一个项目背景迁移多主题"训练；论文行业背景的占用与复用情况见[《00-三科目论文背景行业清单》](00-三科目论文背景行业清单.md)。

## 质量标准

- **判分行**：每卷 75 条、题号 1-75 连续——预览器自动判分依据；
- **答案速查表**：竖排 15 行×5 列，与逐题解析逐格零不一致（高项/架构师 60 卷经全库程序化终检；系规管为早期生成，模式略有差异、已如实登记清单）；
- **答案分布**：A/B/C/D 各约 18-19，防止"背位置"式刷题失效；
- **计算题数字**：EVM/PERT/CPM/决策树/CBAM/可用度/Amdahl 等全部经独立复算自洽；
- **论文行业多样性**：高项与架构师 120 篇范文使用 96 个零重复行业背景。

> 全部模拟题按官方教程知识体系仿真命制，不冒充任何年份真题原文；对记忆模糊的标准编号与年代一律回避，宁换考点不编造。
