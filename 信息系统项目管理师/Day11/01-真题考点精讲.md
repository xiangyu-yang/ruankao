## 二、核心考点精讲

### 考点 1：质量管理三过程总览（先分家）

**考点**：规划质量管理、管理质量（质量保证）、控制质量的分工。
**考法**：过程归属题；"管理质量 vs 控制质量"辨析（高频）。
**速记**：
- **规划质量管理**：识别质量要求与标准，确定如何证明达标——输出质量管理计划与**质量测量指标**；
- **管理质量（质量保证）**：把计划转化为可执行的质量活动、**审计过程是否合规**、改进过程能力——面向**过程**，输出质量报告、测试与评估文件、**变更请求**（过程改进建议）；
- **控制质量**：检查具体可交付成果、**核实的可交付成果**是其标志性输出——面向**产品/成果**；
- 一句话分家："**管理质量管过程（做对了没有），控制质量管产品（做出来的合格没有）**"——"质量审计属于哪个过程"（管理质量）与"核实的可交付成果是哪个过程的输出"（控制质量）是两大送分锚点。

### 考点 2：质量基本概念辨析（送分区）

**考点**：质量与等级、精确与准确、预防与检查。
**考法**：概念对比选择题。
**速记**：
- **质量**：一系列内在特性满足要求的程度；**等级**：对用途相同但技术特性不同的产品或服务的级别分类——**低等级可以是合格产品，低质量永远不合格**（"功能少但可靠"是低等级高质量）；
- **精确**：重复测量的集中程度（聚在一起）；**准确**：测量值与真实值的接近程度——"打得密集但偏离靶心"＝精确不准确；
- **预防（把错误挡在发生前）胜于检查（把错误挑出来）**；**质量是规划、设计、建造出来的，不是检查出来的**。

### 考点 3：质量成本 COQ（与 Day09 呼应再考）

**考点**：一致性/非一致性成本四分类。
**考法**：给费用项目归类。
**速记**：**一致性成本＝预防成本**（培训、流程、质量计划）＋**评价成本**（测试、评审、检验）；**非一致性成本＝内部失败**（返工、报废）＋**外部失败**（保修、索赔、商誉）。考法升级："投培训费降低返工"体现的一致性成本对失败成本的置换关系——质量投入的经济逻辑。

### 考点 4：规划质量的工具（标杆对照等）

**考点**：数据收集与分析工具。
**考法**：给场景选工具。
**速记**：
- **标杆对照（Benchmarking）**：与可比项目的最佳实践对比，识别改进机会与质量标准——"对照行业标杆系统设定性能指标"；
- **头脑风暴、访谈**：收集质量需求与想法；
- **成本效益分析**：质量投入值不值的论证（一致性成本＜预期失败成本即值得）；
- **多标准决策分析**：对质量需求优先级排序（如按影响×紧急度打分）；
- 输出**质量测量指标**必须可测量可验证：缺陷率、故障率、可用率、响应时间、一次通过率——"系统稳定可靠"不是指标，"7×24 可用率 99.9%"才是。

### 考点 5：老七种质量工具（★★★必背表，选择案例双料考点）

**考点**：因果图、流程图、核查表、帕累托图、直方图、控制图、散点图。
**考法**：给用途/场景选工具名（年年必考）；案例中要求用帕累托/因果图分析。
**速记表（背熟即得分）**：

| 工具 | 一句话用途 | 场景关键词 |
|------|-----------|-----------|
| 因果图（鱼骨图/石川图） | **追溯问题根本原因**——结果为头、原因为骨（人机料法环测） | "为什么""根因分析" |
| 流程图 | 展示过程步骤与分支，**预估环节发生质量问题的可能性** | "哪个环节出错" |
| 核查表 | **系统收集/计数**事实数据 | "现场记录缺陷次数" |
| 帕累托图 | 按**发生频率排序的柱状图＋累计百分比曲线**，找"关键的少数"（80/20） | "主要缺陷原因" |
| 直方图 | 展示数据的**分布形态**（对称/偏态/双峰） | "数据整体分布" |
| 控制图 | **判断过程是否稳定受控**，含中心线与控制上下限 | "过程稳定性""七点规则" |
| 散点图 | 显示**两变量间的相关性** | "温度与缺陷率是否相关" |

- **控制图判稳规则（必背）**：数据点**超出控制上下限**、或**连续 7 点落在中心线同一侧**、或**连续 7 点持续上升/下降**——任一情形即判定过程**失控**，须查明特殊原因；控制限在规格限之内则过程有能力满足要求；
- 记忆口诀："**因果找根因、帕累托抓主次、控制图看稳态、散点看相关、直方看分布、流程图找环节、核查表记事实**"；
- 新七工具（了解）：亲和图、关联图、树形（系统）图、矩阵图、优先矩阵、过程决策程序图 PDPC、活动网络图——选择考"哪个不属于老七种工具"。

### 考点 6：管理质量与质量审计（★★★深化重点）

**考点**：质量审计、过程分析、问题解决。
**考法**：审计特征判断（独立性、定期/随机）；审计发现的处理。
**速记**：
- **质量审计**：对质量管理活动的**独立**审查（由项目外部的部门/人员实施更佳），目标是**识别良好实践与差距、确认已批准变更的实施、分享优秀经验、协助改进过程**——审计是"过程体检"，不是追责大会；
- 审计发现→**整改闭环**：问题记录→纠正措施→跟踪验证→关闭归档（"发现问题不整改等于没审计"）；
- **过程分析**：按过程改进计划检查执行中的瓶颈与浪费（非增值活动）；
- 管理质量输出**质量报告**（质量管理体系工作情况的书面汇总）与**测试与评估文件**（描述如何验证符合性）；
- 管理质量期间发现的缺陷整改建议以**变更请求**形式提出——与 Day05 变更控制衔接。

### 考点 7：控制质量的工具

**考点**：检查、测试、统计抽样、核对表。
**考法**：工具归类；数据表现工具在控制中的应用。
**速记**：
- **检查（审查/巡检/同行评审）**：检验工作产品是否符合书面标准——可交付成果验收前的实体把关；
- **测试/产品评估**：验证功能与非功能指标（性能、安全）；
- **统计抽样**：从总体中抽部分检验并**推断总体**（批次抽检）——适用于大批量、破坏性检验场景；
- **问卷与调查**：收集客户满意度等主观数据；
- 老七工具中**因果图、直方图、帕累托图、控制图、散点图**同时也是控制质量的常用工具——"规划找标准、保证查过程、控制用工具验产品"；
- 控制质量发现的不合格→**缺陷**（记入缺陷报告）→ 缺陷补救（变更请求的一种，Day05 已学）→ 纠正后**再检验**；全部达标输出**核实的可交付成果**→ 进入确认范围（客户验收）。

### 考点 8：持续改进与质量管理趋势

**考点**：PDCA、精益六西格玛概要。
**考法**：概念对应。
**速记**：**PDCA（计划-执行-检查-处置）**是持续改进的基本循环（戴明环）；**六西格玛**追求**百万分之 3.4 的缺陷率**（质量水平目标）；**精益**聚焦消除浪费（非增值活动）——"六西格玛降波动、精益去浪费"。

### 考点 9：资源管理六过程总览（先搭骨架）

**考点**：六过程与过程组归属。
**考法**：排序、归属题。
**速记**：**规划资源管理 → 估算活动资源 → 获取资源 → 建设团队 → 管理团队 → 控制资源**——口诀"定规则、估数量、要人手、带队伍、管人心、控物用"。
- 归属：前三个＋控制资源中的规划部分属规划过程组，**建设团队与管理团队属执行过程组，控制资源属监控过程组**；
- 资源分两半：**实物资源**（设备、材料、场地——控制资源管它）与**团队资源**（人——建设与管理团队管它），考试重心在人。

### 考点 10：规划资源管理——RAM/RACI 与组织理论

**考点**：责任分配矩阵、层级型组织图与文本型。
**考法**：RACI 字母含义；图表选型。
**速记**：
- **责任分配矩阵（RAM）**：把工作分配到人——**RACI 矩阵**：**R**（负责执行）、**A**（批准问责，**每行有且仅有一个 A**）、**C**（需咨询）、**I**（需知会）——"每行只能有一个 A"是判断题常客；
- **层级型**（组织分解结构 OBS、资源分解结构 RBS）：显示上下级与资源分组；**文本型**：职责描述文档（岗位说明书式）；
- **组织理论**：说明人员、团队与组织的行为规律，用于设计团队结构、识别团队行为模式。

### 考点 11：塔克曼团队发展阶段（★★★资源板块第一必背）

**考点**：五阶段名称、顺序、特征与管理要点。
**考法**：排序题；给场景判断阶段；阶段→领导风格匹配。
**速记**：**形成（Forming）→ 震荡（Storming）→ 规范（Norming）→ 成熟/发挥（Performing）→ 解散（Adjourning）**——口诀"**形震规成散**"。

| 阶段 | 团队特征 | 管理要点 |
|------|---------|---------|
| 形成 | 初识、客气、目标角色不清 | **指令式**领导：明确目标、规则与分工 |
| 震荡 | 冲突显现、质疑权威、拉帮结派 | **教练式**：直面冲突、疏导分歧、澄清职责 |
| 规范 | 规则内化、协作习惯形成、信任建立 | **参与式**：放手日常工作、强化共识 |
| 成熟/发挥 | 自组织、高效运转、能自主解决问题 | **授权式**：授权决策、只管例外 |
| 解散 | 任务收尾、人员释放、情绪波动 | 收尾认可、经验沉淀、妥善遣散 |

- 经典考法："团队开始出现公开争执、成员质疑经理安排"＝震荡期；"团队自行解决问题无需介入"＝成熟期。

### 考点 12：激励理论大合集（★★★全教程背诵密度之王）

**考点**：马斯洛、赫茨伯格、麦克利兰、期望理论、X-Y、公平理论。
**考法**：给管理做法判断理论依据（高频）；理论内容对应。
**速记表**：

| 理论 | 核心内容 | 考点金句 |
|------|---------|---------|
| 马斯洛需求层次 | 生理→安全→社交→尊重→**自我实现**（五层，低层满足才追求高层） | 最高层＝自我实现 |
| 赫茨伯格双因素 | **保健因素**（工资、工作条件、政策——消除不满）≠**激励因素**（成就、认可、成长——带来满意） | 工资是保健因素，涨工资不等于激励 |
| 麦克利兰三需要 | **成就、权力、亲和**需要（后天习得） | 高成就者爱挑战性目标 |
| 期望理论 | 激励＝**效价×期望值**（目标有价值且我信能实现才有动力） | 两个因子任一为零则激励为零 |
| 麦格雷戈 X-Y | X：人天生懒惰须强制；Y：人愿意工作可自我指挥 | Y 理论支撑授权与参与式管理 |
| 公平理论 | 员工比较"投入/回报比"，感到不公则降低投入 | 同工不同酬引发消极怠工 |

- 高频考法："给员工加薪仍不满"→ 双因素（保健已够、缺激励因素）；"设定跳一跳够得着的目标"→ 期望理论；"让员工参与决策"→ Y 理论。

### 考点 13：冲突管理五法（★★★必背）

**考点**：撤退/回避、缓和/包容、妥协/调解、强迫/命令、合作/解决问题。
**考法**：给场景选方法；"最好/最差方法"判断。
**速记表**：

| 方法 | 一句话 | 适用/代价 |
|------|-------|----------|
| 撤退/回避 | 从冲突中暂时退出，问题推迟 | 冷静期/问题会自行消失；不解决 |
| 缓和/包容 | 强调一致、淡化分歧（求同存异） | 关系优先时；分歧仍存 |
| 妥协/调解 | 各让一步，寻找双方都能接受的中间方案 | 双方力量对等且需速决；双输（各损失一部分） |
| 强迫/命令 | 以权压人，牺牲一方满足另一方 | 紧急决策；输方积怨 |
| **合作/解决问题** | 直面分歧、综合不同观点，寻求**共赢**方案 | 最优方法（费时）；根源性解决 |

- 铁律："**合作/解决问题通常是最优**（时间允许时）；强迫只在紧急时使用；'双赢'只属于合作"——"项目经理应尽量回避冲突"是经典错误项，**冲突应尽早面对、通常在私下处理**。

### 考点 14：其他团队工具与滚动复习区

**速记**：
- **集中办公（作战室）**：把成员集中同一地点提升沟通与团队感；**虚拟团队**：地理分散靠线上协作——两者各有代价（虚拟团队缺面对面、易生孤立感）；
- **认可与奖励**：奖励**可实现的业绩**（只奖励可实现的行为）；团队奖励与个人奖励平衡；
- **团队绩效评价**：通过团队技能提升、人员流动率、凝聚力等指标评估；输入含**团队绩效评价、项目人员派驻单、资源日历**等；
- **问题日志**：管理团队时记录并跟踪问题（Day05 已创建于执行过程，此处用于人际问题管理）。
