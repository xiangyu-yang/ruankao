十大知识领域约 40 题是综合知识的第一大分仓，其中"过程归属、标志性输出、工具归类"三类题几乎全部来自 49 过程 ITTO——记忆负担最重、也最有规律可抓。今天不学新领域，做一次全局串讲：先用"数量骨架＋矩阵"把 49 个过程钉进格子，再用"输出倒推法"和"工具四族法"把 ITTO 压成薄薄几页记忆卡。滚动复习覆盖 Day01-12，Day13（采购与合同）主题以标准教材口径纳入 3 题。

## 二、核心考点精讲

### 考点 1：49 过程的数量骨架（先背数字再填名字）

**考点**：领域过程数、过程组过程数。
**考法**：数量题直接送分。
**速记**：
- **49＝7＋6＋6＋4＋3＋6＋3＋7＋3＋4**：整合 7、范围 6、进度 6、成本 4、质量 3、资源 6、沟通 3、风险 7、采购 3、干系人 4；
- 按过程组：**启动 2、规划 24、执行 10、监控 12、收尾 1**——口诀"两启廿四规，十执十二监，一收尾"；
- **过程数为 7 的领域只有两个：整合与风险；过程数为 3 的领域：质量、沟通、采购**。

### 考点 2：过程组×知识领域矩阵（归属题的总钥匙）

**考点**：每个过程的过程组与领域归属。
**考法**：给过程名选归属（"属于/不属于哪个过程组或领域"）、给描述定过程。
**速记（只背易错点）**：
- 启动：制定项目章程、识别干系人（仅 2 个）；
- **易错归属一**："确认范围"属**监控**过程组（不是执行）；"质量控制"也是监控；
- **易错归属二**："实施风险应对"属**执行**过程组（监督风险才是监控）——"应对是干活、监督是盯梢"；
- **易错归属三**："管理质量"属执行（把计划变成质量活动），"控制质量"属监控（检查核验）；
- 收尾只有"结束项目或阶段"（整合领域）；
- 规划 24 个里没有"监控风险、控制进度"这类"控制"字样过程——**"控制××""监督××"基本在监控组**，唯一例外："控制质量"当然也在监控。

### 考点 3：标志性输出倒推法（ITTO 的捷径）

**考点**：一批"标志性输出"的产出过程。
**考法**："××文件/成果是哪个过程的输出"——高频！
**速记表**：

| 标志性输出 | 产出过程 | 领域 |
|-----------|---------|------|
| 项目章程 | 制定项目章程 | 整合×启动 |
| 干系人登记册 | 识别干系人 | 干系人×启动 |
| 需求文件、需求跟踪矩阵 | 收集需求 | 范围×规划 |
| 范围说明书（范围基准三件套） | 定义范围＋创建 WBS | 范围×规划 |
| 活动清单、里程碑清单 | 定义活动 | 进度×规划 |
| 进度基准 | 制订进度计划 | 进度×规划 |
| 成本基准 | 制定预算 | 成本×规划 |
| 质量管理计划、质量测量指标 | 规划质量管理 | 质量×规划 |
| 资源分解结构 | 估算活动资源 | 资源×规划 |
| 沟通管理计划 | 规划沟通管理 | 沟通×规划 |
| 风险登记册（首次形成） | 识别风险 | 风险×规划 |
| 采购策略、采购工作说明书 | 规划采购管理 | 采购×规划 |
| 可交付成果、工作绩效数据、问题日志 | 指导与管理项目工作 | 整合×执行 |
| 经验教训登记册 | 管理项目知识 | 整合×执行 |
| 质量报告、测试与评估文件 | 管理质量 | 质量×执行 |
| 变更请求 | 多个执行与监控过程 | — |
| 批准的变更请求 | 实施整体变更控制的输出，交由指导与管理项目工作执行 | 整合×监控 |

### 考点 4：绩效信息三级链（数据→信息→报告）

**考点**：工作绩效数据/信息/报告的流转。
**考法**：链条排序、产出过程对应。
**速记**：执行过程产出**工作绩效数据**（原始记录）→ 各"控制××"过程把它加工成**工作绩效信息**（比对基准后的分析）→ **监控项目工作**（整合领域×监控）汇总成**工作绩效报告**（决策层输入）——"数据是矿石、信息是冶炼、报告是钢锭"。

### 考点 5：高频工具技术四族归类（串讲）

**考点**：49 过程的工具技术按族归类。
**考法**：给工具名归族、给场景选工具。
**速记（四族法）**：
- **数据收集族**：访谈、问卷、标杆对照、检查表、头脑风暴；
- **数据分析族**：备选方案分析、成本效益分析、偏差分析、根本原因分析（RCA）、假设情景分析、敏感性分析、质量成本（COQ）、绩效审查；
- **决策族**：多标准决策分析、投票（一致同意/多数同意/相对多数）、独裁（autocratic）；
- **人际关系与团队技能族**：冲突管理、引导（促进）、名义小组、观察与交谈、积极倾听、文化/政治意识、沟通风格评估；
- **两大"万能工具"**：**专家判断**（49 过程中出现次数最多）与**会议**（几乎贯穿全程）；
- 记忆锚：**审计**有三兄弟——质量审计（管理质量）、风险审计（监督风险）、采购审计（控制采购）；**检查**＋**统计抽样**＋**测试**＋**评审**是控制质量的看家工具。

### 考点 6：裁剪——ITTO 串讲的灵魂

**考点**：项目管理过程裁剪的原则。
**考法**：裁剪判断题（近年新增）。
**速记**：49 过程是"菜单"不是"套餐"——应依据**项目规模、复杂程度、行业特性、组织政策与生命周期类型**裁剪过程、工具与文档：小项目可合并过程、简化模板；敏捷项目用迭代计划替代重规划文档。两个极端都是错：**全盘照搬是官僚，全盘不用是裸奔**。

### 考点 7：滚动复习区（Day01-13 高频错题回炉）

- 三大基准＋项目管理计划＝绩效测量基准（PMB）；基准变更走整体变更控制；
- 挣值四指标与 EAC 三公式；TCPI 与"追加预算或提效"的决策；
- 权力-利益四象限与威胁四策略；EMV 敞口与应急储备；
- 等保五动作、签名用私钥、日志六个月；SLA/OLA/UC；完善性维护占比最大；
- 招投标：招标文件发出至投标截止最短 20 日；固定总价买方风险最小。

## 三、今日考法规律总览（真题视角）

1. ITTO 类选择题的三大题型：过程归属、标志性输出归属、工具归类——今天的速记表覆盖九成考面；
2. 归属题专盯易错点出题：确认范围（监控）、实施风险应对（执行）、管理质量（执行）是三大陷阱；
3. 裁剪与绩效信息链条是近年新增考法，去年开始稳定出现；
4. 今日考点在案例中的形态：过程裁剪找茬、矩阵分析题（给过程写归属）、绩效链条简答。
