## 题库容量

- **综合知识**：30 卷 × 75 题 = **2250 道**单选题（含专业英语 150 题）
- **案例分析**：30 卷 × 3 大题 = **90 道**（计算题全程覆盖：CPM/PERT/EVM 全家桶/决策树/EMV/评标/索赔/COQ）
- **论文**：30 卷 × 2 题 = **60 篇** 2500 字级范文（十大领域＋绩效域/项目集/合规/收益管理等多轮主题，覆盖第一轮、第二轮深化、第三轮背诵版三种形态）

## 结构说明

每日五件套（`01-精讲` / `02-试题` / `03-答案与解析` / `04-案例` / `05-论文`）说明见仓库根目录 [README](../README.md)。全真模拟日（Day15/18/21/25）与专项日使用特化文件名。

## 训练使用建议

- **选择题**：用 `备考学习预览器.html` 打开 02 试题即进入练习模式——作答、交卷判分、错题回顾一体完成；速查表与逐题解析逐格一致，判分可靠；
- **计算题**：以 Day10/19/29 三张计算公式卡为纲，对 Day07-09 及各模拟卷的计算大题反复演算至"公式→代入→结论"条件反射；
- **论文**：先读 Day22-24 的结构解剖与精读方法，再用各卷范文做"换题重写"训练（同一项目背景迁移到不同主题）；行业背景占用见[《00-三科目论文背景行业清单》](../00-三科目论文背景行业清单.md)。

## 质量说明

本目录 30 卷经全库程序化终检：判分行 75 条题号连续、速查表与解析逐格零不一致、答案分布 A/B/C/D 各约 18-19。全部模拟题按官方教程（第4版）知识体系仿真命制，不冒充任何年份真题原文。
