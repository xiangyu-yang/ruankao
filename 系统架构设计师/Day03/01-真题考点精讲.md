# Day03 真题考点精讲 · 计算机网络与信息安全

> Day03 ｜ 主题：网络体系结构与协议＋IP 与子网计算＋传输层机制＋信息安全（加密/认证/攻击/防护）｜ 对应教程计算机网络与信息安全基础章节

## 一、今天在考纲中的位置

网络与信息安全是综合知识选择题的"第二得分大户"：网络部分稳定出 8-12 题（其中子网与信道容量计算必出 3-4 题），信息安全稳定出 6-10 题；案例分析的选做题池里"网络规划与安全体系"是常见题型；论文中"安全架构""高并发网络架构"都是高频主题。今天的特点是**记忆点密集、计算题模板化**——两类都要拿下。

## 二、核心考点精讲

### 考点 1：网络体系结构（OSI 七层与 TCP/IP 四层）

**考点**：层次划分、各层功能与设备对应。
**考法**：层序排列、设备工作层次、数据单位对应。
**速记**：
- OSI 七层自下而上：**物理→数据链路→网络→传输→会话→表示→应用**（口诀"物数网传会表应"）；
- TCP/IP 四层：**网络接口→网际→传输→应用**（网际层≈OSI 网络层，传输层对应一致）；
- 设备与层次：**中继器/集线器→物理层；网桥/交换机→数据链路层；路由器→网络层；网关→高层**；
- 数据单位：物理层比特→链路层**帧**→网络层**分组**→传输层**报文段**→应用层报文——"单位错位"是经典陷阱。

### 考点 2：IP 地址与子网划分（计算题高产区）

**考点**：地址分类、子网掩码、VLSM/CIDR。
**考法**：给掩码求主机数、给 IP/掩码求网络地址与广播地址、借位划分子网。
**速记**：
- 分类：A 类 1-126（默认 /8）、B 类 128-191（/16）、C 类 192-223（/24）；**私有地址**三段：10.0.0.0/8、172.16.0.0-172.31.255.255、192.168.0.0/16；
- 可用主机数＝**2^(主机位)−2**（减网络地址与广播地址）；/26→62、/27→30、/28→14、/29→6、/30→2；
- 网络地址＝IP 与掩码按位与；块大小＝256−掩码最后一非 255 字节值（/27 块=32）；
- **VLSM**：可变长子网掩码，按部门规模"先大后小"分配；**CIDR**：无类别域间路由，前缀可变、支持路由聚合（如把 4 个 /24 聚合为 1 个 /22）；
- 计算模板：IP→二进制→与掩码对齐→借位分组→块边界定位网络/广播地址。

### 考点 3：信道容量计算（奈奎斯特与香农）

**考点**：无噪声/有噪声信道的极限速率。
**考法**：公式代数计算选择题。
**速记**：
- **奈奎斯特（无噪声）**：C＝**2W·log₂V**（W 带宽 Hz，V 码元离散状态数）——如 4kHz 带宽、16 种状态：C＝2×4000×4＝32kbps；
- **香农（有噪声）**：C＝**W·log₂(1+S/N)**——信噪比 dB 值要先换算：**dB＝10·lg(S/N)**，30dB→S/N＝1000；3kHz、30dB：C≈3000×9.97≈30kbps；
- 陷阱：dB 不是比值本身；香农给出的是"不可逾越的上限"。

### 考点 4：传输层（TCP 三次握手/四次挥手/滑动窗口）

**考点**：连接管理状态机、TCP 与 UDP 对比、可靠传输机制。
**考法**：握手挥手报文与状态、机制归属判断。
**速记**：
- **三次握手**：SYN→SYN+ACK→ACK；为什么不是两次：防止失效的旧连接请求造成资源错配；
- **四次挥手**：FIN→ACK→FIN→ACK；主动方最后进入 **TIME_WAIT**（等待 2MSL：确保最后 ACK 送达并让旧报文消亡）；
- **SYN 泛洪**＝只发 SYN 不完成握手，堆积半连接耗尽资源；
- TCP vs UDP：**TCP 面向连接、可靠有序、流量与拥塞控制**，适合文件/网页/邮件；**UDP 无连接、开销小、实时性好**，适合直播、DNS、DHCP；
- **滑动窗口＝流量控制**（接收方通告窗口）；可靠性核心＝序列号＋确认＋超时重传＋校验。

### 考点 5：应用层协议与端口（送分区，端口必背）

| 协议 | 端口 | 要点 |
|------|------|------|
| HTTP | 80 | 明文网页传输 |
| HTTPS | 443 | HTTP＋TLS/SSL 加密与证书认证 |
| DNS | 53 | 主要 UDP；域名→IP，递归/迭代查询 |
| FTP | 21（控制）/20（数据） | 双连接：控制连接＋数据连接 |
| SSH | 22 | 加密远程登录（Telnet 23 明文） |
| SMTP | 25 | 发邮件；POP3 110/IMAP 收邮件 |
| DHCP | 67/68 | 动态分配 IP/掩码/网关/DNS，租约机制 |

**考法**：端口与协议配对、协议功能判断、明文/加密协议辨析。

### 考点 6：交换与路由（VLAN、NAT、RIP/OSPF）

**考点**：VLAN 隔离原理、NAT 作用、路由协议对比。
**速记**：
- **VLAN**：逻辑隔离**广播域**，提升安全与管理性；**VLAN 间通信必须经三层设备**（路由器/三层交换机）；
- **NAT**：私有地址与公网地址转换，缓解 IPv4 枯竭、隐藏内网结构；
- 路由协议对比（年年考）：

| 维度 | RIP | OSPF |
|------|-----|------|
| 类型 | 距离向量 | **链路状态** |
| 度量 | 跳数，**最大 15 跳**（16 不可达） | 开销（带宽相关） |
| 算法 | 周期广播路由表 | **Dijkstra 最短路径**，泛洪 LSA |
| 收敛 | 慢，易环路 | 快，**支持区域划分**，适合大型网络 |

### 考点 7：网络规划要点（综合布线/SDN/IPv6）

**考点**：综合布线六子系统、SDN 思想、IPv6 特性。
**速记**：
- **综合布线六子系统**：工作区、水平（配线）、垂直干线、设备间、管理、建筑群——"工作水平垂直、设备管理建筑群"；
- **SDN**：**控制平面与数据转发平面分离**，控制器集中编程（南向控制转发、北向开放应用）；
- **IPv6**：地址 **128 位**、地址空间充足、首部简化、内置 IPSec 支持、无需 NAT、即插即用（自动配置）。

### 考点 8：加密体制（对称/非对称/混合）

**考点**：三类体制原理与适用。
**速记**：
- **对称加密**：加解密**同一密钥**，速度快，适合大数据量；难点是**密钥分发**；代表 DES、3DES、**AES**、RC4；
- **非对称加密**：公钥/私钥成对，**公钥加密→私钥解密**（保密）；**私钥签名→公钥验证**（认证）；速度慢，代表 **RSA**、ECC、国密 SM2；
- **混合加密（数字信封）**：用对称密钥加密数据、用**接收方公钥**加密该对称密钥一起发送——兼顾效率与密钥分发安全。

### 考点 9：摘要与数字签名

**考点**：单向散列特性、签名的功能组合。
**速记**：
- 消息摘要：**单向不可逆、输出定长、雪崩效应**（原文微变摘要大变）；代表 MD5、SHA 系列；口令存储用"加盐摘要"，**绝不存明文**；
- 数字签名＝**对摘要用私钥加密**；能同时实现**完整性＋身份认证＋不可抵赖**，**不能提供机密性**——"签名不保密、加密不签名"，需保密再叠加加密。

### 考点 10：密钥管理与 PKI

**考点**：数字证书、CA、PKI 组成。
**速记**：
- **数字证书**＝把"公钥与身份"绑定并由 **CA 私钥签名**背书的载体；
- **CA** 负责证书签发、更新、吊销（**CRL 吊销列表**/OCSP 查询）；
- PKI 组成：CA/RA（注册审批）、证书库、密钥备份恢复、应用接口；
- 密钥管理原则：私钥**绝不**交给 CA 托管（CA 只管公钥），密钥全生命周期（生成/分发/更新/吊销/归档）管控。

### 考点 11：身份认证（Kerberos 思想）

**考点**：认证因素、Kerberos 票据思想。
**速记**：
- 三因素：**你知道的（口令）、你拥有的（令牌/证书）、你的生物特征**——两两组合即"双因素认证"；
- **Kerberos**：基于**对称加密＋可信第三方（KDC）**；先用口令向认证服务器换取票据（TGT），再用票据向票据授权服务换服务票据访问资源——**口令不在线路上传输**、票据有有效期是其核心思想。

### 考点 12：常见攻击与防护（场景判断题）

**考法**：给攻击现象判断类型、给防护手段判断针对的攻击。
**速记**：

| 攻击 | 特征 | 防护 |
|------|------|------|
| DDoS | 傀儡机协同耗尽带宽/连接资源 | 流量清洗、CDN 分流、限流、弹性扩容 |
| SQL 注入 | 拼接恶意 SQL 篡改查询 | **参数化查询/预编译**、最小权限、WAF |
| XSS | 向页面注入恶意脚本窃取会话 | 输出编码转义、HttpOnly Cookie、CSP |
| 钓鱼 | 仿冒可信站点/邮件骗取口令 | 安全意识培训、统一入口、双因素 |
| 蠕虫 | **独立存在、自我复制主动传播**（区别病毒需宿主） | 补丁管理、网络分段 |
| 勒索病毒 | 加密文件勒索 | 备份、最小权限、终端防护 |

### 考点 13：安全协议（IPSec/SSL/SET）

**速记**：
- **IPSec**：网络层安全协议，含 AH（认证）与 ESP（加密+认证）；**传输模式**保护端到端载荷，**隧道模式**封装整个 IP 包——站点间 VPN 用隧道模式；
- **SSL/TLS**：位于**传输层与应用层之间**，为 HTTP 等提供加密与完整性（HTTPS）；
- **SET**：安全电子交易协议，用于网上银行卡支付，多方（持卡人/商家/网关/银行）证书互信。

### 考点 14：防火墙与 IDS/IPS

**速记**：
- 包过滤防火墙：**网络层**，按 IP/端口规则放行——快但不能防应用层攻击；应用代理防火墙：应用层，更安全但性能开销大；
- 防火墙局限：**防不了内部攻击、绕行连接、病毒传播**；
- **IDS**：旁路部署，侦听分析＋告警，一般不阻断；**IPS**：串联部署，可**实时阻断**——"旁路报警 vs 串接拦截"是判断题眼。

### 考点 15：VPN

**速记**：
- 核心思想：**利用隧道协议在公用网络上建立加密通道**，实现机密性＋身份认证＋完整性；
- **IPSec VPN**（网络层）：站点到站点互联，适合分支与总部；
- **SSL VPN**（应用层/传输层）：免客户端或轻客户端，适合出差员工远程接入；
- 部署要点：双因素认证、最小权限访问控制、日志审计。
