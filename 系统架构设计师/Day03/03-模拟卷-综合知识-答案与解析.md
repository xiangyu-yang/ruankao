## 二、逐题解析（每题一答一析）

**1. A**【OSI层次】七层自下而上为物理、数据链路、网络、传输、会话、表示、应用（口诀"物数网传会表应"）；B 交换了链路层与网络层，D 交换了传输与会话。

**2. B**【设备层次】路由器依据 IP 地址跨网段转发分组，工作在网络层；物理层为中继器/集线器，链路层为网桥/交换机。

**3. C**【设备层次】以太网交换机基于 MAC 地址表转发帧，工作在数据链路层；具备路由功能的三层交换机才涉及网络层。

**4. D**【TCP/IP模型】TCP/IP 的网际层（IP 层）与 OSI 网络层功能对应：寻址与路由；传输层两层一一对应。

**5. A**【数据单位】数据链路层以"帧"为单位；物理层传比特、网络层传分组、传输层传报文段——单位与层次的错位配对是常设陷阱。

**6. C**【传输层功能】传输层提供端到端（进程到进程）的数据传输服务，如 TCP/UDP；A 是网络层功能，B 是物理层功能，D 是链路层功能。

**7. A**【设备层次】集线器只对比特信号放大转发，属物理层；交换机在链路层，路由器在网络层，网关工作在高层。

**8. D**【IP分类】首字节 172 落在 128-191 区间，属 B 类地址（默认掩码 /16）。

**9. B**【私有地址】私有地址三段：10.0.0.0/8、172.16.0.0—172.31.255.255、192.168.0.0/16；172.32.1.1 已超出 172.16-31 范围，是公网地址。

**10. C**【子网计算】255.255.255.240＝/28，主机位 4 位，可用主机数＝2⁴−2＝14（扣除网络地址与广播地址）。

**11. B**【子网计算】/26 的主机位为 6 位，可用主机数＝2⁶−2＝62；64 是地址总数、126 是 /25 的可用数。

**12. A**【借位计算】划分 4 个子网需借 n 位使 2ⁿ≥4，n＝2；借 2 位后每个子网主机位 6 位、可用 62 台，规模正好。

**13. D**【CIDR】CIDR 摆脱 A/B/C 类边界，采用"IP+前缀长度"（如 /22）编址，并支持把多条路由聚合为一条，缩减路由表规模。

**14. B**【VLSM】VLSM 允许同一网络内按部门规模划出大小不同的子网（先大后小分配），提高地址利用率；固定长度掩码是 FLSM。

**15. C**【子网计算】/27 块大小＝256−224＝32，子网边界：0、32、64、96…；77 落在 64-95 块内，网络地址 192.168.10.64，广播地址 192.168.10.95（可用范围 .65—.94）。

**16. A**【奈奎斯特】无噪声极限数据率 C＝2W·log₂V＝2×4000×log₂16＝8000×4＝32kbps。

**17. B**【香农】30dB 换算：S/N＝10^(30/10)＝1000；C＝W·log₂(1+S/N)＝3000×log₂(1001)≈3000×9.97≈30kbps。注意 dB 必须先换算为功率比。

**18. D**【三次握手】第二次握手是服务器对 SYN 的确认并同时发起自己的同步，报文携带 SYN+ACK 两个标志位。

**19. B**【四次挥手】主动关闭方发出最后一个 ACK 后进入 TIME_WAIT，等待 2MSL：一是确保最后的 ACK 能重发送达，二是让旧连接报文在网络中消亡。

**20. A**【SYN泛洪】攻击者海量发送 SYN 却不回应第三次握手，服务器半连接队列被占满拒绝服务；SYN Cookie、缩短半连接超时是应对手段。

**21. C**【TCP/UDP对比】TCP 面向连接、可靠有序、有流量与拥塞控制；UDP 无连接、开销小、实时性好。A 方向说反，D 场景说反。

**22. A**【滑动窗口】滑动窗口本质是流量控制：接收方通过通告窗口限制发送方速率，防止接收缓冲被冲垮。

**23. D**【TCP可靠性】序列号+确认、超时重传、校验和都是 TCP 可靠机制；"广播风暴抑制"是二层交换网络的概念，与 TCP 无关。

**24. C**【UDP场景】实时视频直播可容忍少量丢包但要求低时延，选 UDP；网页、邮件、文件传输都要求可靠有序，用 TCP。

**25. B**【端口】HTTP 默认 TCP 80；21 是 FTP 控制、443 是 HTTPS、25 是 SMTP。

**26. D**【端口】HTTPS＝HTTP over TLS/SSL，默认端口 443；80 是明文 HTTP。

**27. A**【端口】DNS 默认使用 UDP 53（区域传送等少数场景用 TCP 53）；查询报文小、追求效率。

**28. C**【端口】FTP 控制连接默认 TCP 21，数据连接默认 20；FTP 采用"控制+数据"双连接设计。

**29. B**【DHCP】DHCP 为主机动态下发 IP、掩码、网关、DNS 等参数并按租约管理；域名解析是 DNS 的职责。

**30. D**【综合布线】水平子系统连接楼层配线间与工作区信息插座；垂直干线子系统连接各楼层设备间，建筑群子系统连接不同建筑物。

**31. A**【VLAN】VLAN 在交换机上逻辑划分广播域，隔离广播、提升安全与管理的灵活性；它不增加物理带宽也不替代防火墙。

**32. C**【VLAN间通信】不同 VLAN 属不同网段，二层数据链路层无法互通，必须经三层设备（路由器或三层交换机）路由转发。

**33. B**【NAT】NAT 在出口完成私有地址与公网地址转换，缓解 IPv4 地址枯竭并隐藏内网结构；加密、解析均非其职责。

**34. D**【RIP】RIP 是距离向量协议：以跳数为度量、周期性交换路由表、最大 15 跳（16 视为不可达）、收敛慢易环路。

**35. A**【OSPF】OSPF 是链路状态协议：泛洪 LSA 同步拓扑、Dijkstra 计算最短路径、支持区域划分、收敛快，适合大型网络。

**36. C**【路由选型】多区域+快速收敛的大型网络选 OSPF；RIP 受 15 跳与慢收敛限制，ARP 是地址解析协议并非路由协议。

**37. B**【SDN】SDN 的本质是控制平面与数据转发平面分离，控制集中到控制器并通过标准接口（南向）驱动转发、（北向）开放编程。

**38. A**【IPv6】IPv6 地址 128 位，地址空间约 3.4×10³⁸，首部简化、内置 IPSec 支持、支持无状态自动配置。

**39. C**【安全三要素】防篡改＝完整性；机密性防泄露（加密），可用性防中断（抗 DDoS），不可抵赖靠数字签名实现。

**40. A**【对称加密】对称加密加解密同钥、速度快，适合大数据量加密；软肋在密钥分发与管理规模（n 人两两保密需大量密钥）。

**41. D**【算法归类】AES 是对称加密；RSA、ECC 是非对称；SHA-256 是散列算法不是加密算法。

**42. B**【非对称加密】公私钥成对、可公开公钥解决分发问题并支持签名，但运算慢；安全强度取决于密钥长度与算法，并非天生低于对称。

**43. A**【数字签名】签名＝发送方用"自己私钥"对摘要加密；验证＝任何人都可用"发送方公钥"检验，从而认证身份且不可抵赖。

**44. D**【数字信封】混合加密中数据用对称密钥加密，会话密钥用"接收方公钥"加密后随密文发送，只有接收方能用私钥取出会话密钥。

**45. C**【消息摘要】摘要算法单向不可逆、输出定长（如 MD5 为 128 位）、具备雪崩效应；它没有密钥，谈不上加解密同钥。

**46. D**【签名功能】签名同时实现完整性验证、身份认证与不可抵赖三项功能，但不提供机密性——需保密须另加加密（或采用"签名+加密"）。

**47. B**【口令存储】口令应"加盐+单向散列"存储；盐使相同口令摘要不同、抵御彩虹表；Base64 是编码不是保护。

**48. D**【数字证书】证书把"公钥与身份"绑定并由 CA 签名背书，解决"公钥属于谁"的信任问题，本身不加密业务数据。

**49. C**【CA职责】CA 负责证书全生命周期管理：签发、更新、吊销并发布 CRL/OCSP 查询；私钥由用户自持，CA 绝不托管。

**50. A**【Kerberos】Kerberos 以对称加密为基础、由可信第三方 KDC 颁发票据（先取 TGT 再换取服务票据），口令本身不在网络上传送。

**51. B**【双因素】双因素＝两个不同类别的因素：你知道的（口令）＋你拥有的（令牌/智能卡）；两个口令仍是单因素。

**52. D**【DDoS】DDoS 靠傀儡网络协同发起海量请求，耗尽目标带宽或连接资源，使正常用户无法访问；防护靠流量清洗、CDN 分流、限流扩容。

**53. C**【SQL注入】根治注入靠参数化查询（预编译），用户输入只作数据不作 SQL 代码；隐藏报错、换品牌都治标不治本。

**54. A**【XSS防护】XSS 的根因是恶意内容未经处理进入页面，防护核心是输入/输出编码转义，辅以 HttpOnly Cookie、CSP 策略。

**55. B**【钓鱼】钓鱼＝仿冒可信网站/邮件诱骗用户主动交出凭据，属社会工程学攻击，技术武器库对其作用有限，意识培训是关键。

**56. D**【蠕虫】蠕虫不需宿主程序、可自我复制主动传播；病毒依附宿主，木马伪装潜伏不自我复制，逻辑炸弹需条件触发。

**57. C**【包过滤防火墙】包过滤在网络层依据 IP、端口等报头五元组规则放行/丢弃，速度快但看不见应用层内容。

**58. D**【防火墙局限】防火墙守边界，防不了内部人员攻击、绕行连接（如私自拨号）与应用层内容型攻击；须与 IDS/IPS、主机防护配合。

**59. B**【IDS】IDS 旁路镜像侦听流量、分析并告警，一般不直接阻断；"只报不拦"是与 IPS 的根本差异点。

**60. D**【IDS/IPS】IDS 旁路部署、以检测告警为主；IPS 串接在流量路径上，可对入侵行为实时丢弃/阻断，代价是误拦风险。

**61. C**【IPSec模式】隧道模式把整个原始 IP 包加密封装进新 IP 头，用于网关间（站点到站点）VPN；传输模式只保护载荷，用于端到端。

**62. B**【SSL/TLS】SSL/TLS 架在 TCP 之上、应用协议之下（传输层与应用层之间），为 HTTP 等应用提供加密、完整性与身份认证。

**63. A**【SET协议】SET 是网上银行卡支付的安全电子交易协议，持卡人、商家、支付网关、银行多方通过证书互信，交易信息分段隔离。

**64. A**【VPN】VPN 的核心是隧道技术：在公网上用隧道协议封装并加密数据，形成逻辑上的专用通道；VLAN、NAT 都不是 VPN 机制。

**65. B**【安全接入】远程办公的机密性与强认证需求由 VPN（IPSec/SSL VPN）满足；HTTP 明文、FTP、Telnet 全部不安全。

**66. C**【RAID5容量】可用容量＝(n−1)×单盘＝7×4＝28TB，一块盘的容量作分布式校验。（Day01 滚动复习）

**67. A**【可用度】A＝MTBF/(MTBF+MTTR)＝8760/8784≈0.9973＝99.7%；99.97% 需 MTTR 约 2.6 小时。（Day01 滚动复习）

**68. D**【进程线程】进程是资源分配单位、线程是调度执行单位，同进程内线程共享地址空间与资源；切换开销通常线程更小。（Day02 滚动复习）

**69. B**【死锁条件】死锁四必要条件：互斥、请求与保持、不可抢占（不剥夺）、循环等待；"可抢占"恰恰是破坏死锁的手段。（Day02 滚动复习）

**70. C**【范式】"非主属性完全依赖码（消部分依赖）且无传递依赖"即 3NF 定义；2NF 只消部分依赖，BCNF 还要求所有决定因素都是候选码。（Day02 滚动复习）

**71. A**【英语】OSI 中负责跨网络路由分组的是 network（网络）层；physical 是比特传输，session 管会话。

**72. B**【英语】把一个 IP 网络划分为多个小子网用的是 subnet（子网）掩码；window 是 TCP 滑动窗口。

**73. C**【英语】DNS 把可读的域名翻译成 IP 地址（IP addresses）。

**74. D**【英语】用接收方公钥加密提供 confidentiality（机密性）；签名才提供 non-repudiation。

**75. A**【英语】VPN 在公共网络上建立加密隧道支持安全远程访问；VLAN 是局域网逻辑分段。
