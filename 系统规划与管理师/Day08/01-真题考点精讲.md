## 一、全真模拟执行规范（照做，练出考试生物钟）

1. **时间纪律**：单题平均2分钟；60分钟内完成第一遍，标记不确定题；剩余时间回检＋涂卡式确认（机考直接点选）；到点必停。
2. **仿真环境**：手机静音放另一房间；桌面只留水杯；中间不查任何资料。
3. **案例策略**：先通读三题→按"先易后难"排序→每题先看问题再读材料→按点编号作答→计算题写"公式→代入→结果"。
4. **复盘规范**（下午做，30-45分钟/科）：每道错题标注错因三类之一——**A概念不清/B概念混淆/C审题失误**；A类回教材小节重读，B类把混淆对抄进错题本对照栏，C类给自己定一条审题检查动作（如圈出"不属于/错误的是"）。

## 二、第1-10章高频易错点串讲（考前必过清单）

### 基础篇（第1-3章）

| 易错点 | 正确记忆 |
|--------|----------|
| 数据vs信息 | 数据是原始记录，信息是加工后有意义的数据；信息消除不确定性 |
| 诺兰六阶段 | 初装→蔓延→控制→集成→数据管理→成熟（"蔓延"各自为政、"控制"开始管控） |
| 软件维护占比 | 完善性维护工作量最大（不是纠正性） |
| 事务ACID | 原子A、一致C、隔离I、持久D；"并发事务互不干扰"＝隔离性 |
| OSI设备 | 交换机→数据链路层；路由器→网络层；网关→高层 |
| TCP三次握手 | 建连三次、断开四次 |
| 大数据5V | 无Visualization！Value是价值密度低 |
| 机器学习三分类 | 监督（有标签）/无监督（聚类）/强化（奖赏试错） |
| 数字经济四化 | 传统产业改造＝产业数字化；ICT产业本身＝数字产业化 |
| 2522框架 | 两大基础＝基础设施＋数据资源；两大能力＝创新体系＋安全屏障（勿互换） |
| 老三论/新三论 | 老三论：系统、信息、控制；新三论：耗散、协同、突变 |
| 信息定义 | 香农：消除不确定性；不是"数据的集合" |

### 方法篇（第4-10章）

| 易错点 | 正确记忆 |
|--------|----------|
| BSP方向 | **自上而下识别**目标/过程/数据类，**自下而上设计**系统（IBM提出） |
| VCA分类 | 辅助活动四项：企业基础设施、人力资源管理、技术开发、**采购** |
| 可行性 | 技术/经济/**法律（社会）**/运行（操作）——"用户愿不愿用"＝运行可行性 |
| 系统分析vs设计 | 分析＝逻辑模型（做什么）；设计＝物理模型（怎么做） |
| 生命周期选择 | 需求稳定→瀑布；需求不清→原型；**风险驱动→螺旋**；多变快交付→敏捷 |
| TOGAF | 核心是ADM；四架构业务→数据/应用→技术 |
| IaaS/PaaS/SaaS | 给裸资源IaaS、给平台PaaS、给软件SaaS；案例中"自装OS"＝IaaS |
| NIST五特征 | 按需自服务、广泛接入、**资源池化**、快速弹性、**可度量**；无"免费" |
| 四种部署 | 公有/私有/社区/混合；"核心自建＋弹性租用"＝混合 |
| 存储四形态 | DAS直连、NAS文件级、SAN块级、对象存储（海量非结构化） |
| PUE | 总能耗/IT能耗，越接近1越好；1.3为先进水平 |
| 布线六子系统 | 工作区、水平、垂直干线、管理、设备间、建筑群 |
| 5G三场景 | eMBB大带宽、uRLLC低时延（自动驾驶）、mMTC大连接（抄表） |
| 数据模型三层 | 概念（E-R）→逻辑（关系模式）→物理（存储结构） |
| 数据标准化 | 元数据（描述数据的数据）→数据元（对象/特性/表示）→分类编码 |
| 等保五动作 | **定级→备案→建设整改→等级测评→监督检查** |
| 加密算法 | 对称：DES/3DES/AES；非对称：RSA/ECC；签名＝私钥签、公钥验 |
| 云原生四件套 | 容器、微服务、DevOps、持续交付；K8s最小单位＝Pod |
