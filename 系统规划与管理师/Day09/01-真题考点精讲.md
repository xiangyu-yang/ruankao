## 一、能力篇高频易错点清单（做题前10分钟过一遍）

### 治理与审计（第11章）
| 易错点 | 正确记忆 |
|--------|----------|
| 治理vs管理 | 治理定方向建机制（投资决策、问责）；管理执行落地 |
| COBIT结构 | 分"治理目标（EDM）"与"管理目标"两大部分，治理聚焦价值/风险/资源 |
| 审计流程 | 准备→实施→报告→**跟踪**（漏跟踪＝流程未闭环） |
| 一般vs应用控制 | 一般控制＝基础设施/安全/运维（环境类）；应用控制＝输入/处理/输出（业务类） |
| 审计独立性 | 参与被审系统开发、隶属被审条线均损害独立性 |

### 服务管理（第12章）——本卷16题主力
| 易错点 | 正确记忆 |
|--------|----------|
| 需求识别五项 | 可用性、连续性、**能力（容量）**、信息安全、价格 |
| SLA/OLA/UC | 外签客户、内签部门、签外部供应商 |
| 响应vs解决 | 响应＝受理回复时限；解决＝处理完毕时限 |
| 事件vs问题 | 事件治标（尽快恢复）；问题治本（根因消除） |
| 职能升级vs层级升级 | 职能＝转更高技术能力线；层级＝管理层上报 |
| 变更类型 | 标准变更＝预授权低风险；重大变更＝CAB评估 |
| 配置项vs资产 | 配置管理面向"服务与交付"，含关系；资产管理面向"价值与折旧" |
| 一线解决率 | 过程指标；满意度＝服务指标；MTBF＝技术指标 |
| 服务退役 | 沟通、风控、资源回收、信息处置（**留处置记录**） |
| 满意度卡诺 | 基本型无感、期望型线性、兴奋型惊喜 |
| 预算/核算/结算 | 事前规划／如实反映／收口对账 |

### 人员管理（第13章）
| 易错点 | 正确记忆 |
|--------|----------|
| 柯氏四级 | 反应（满意）→学习（掌握）→行为（回岗改变）→结果（组织绩效） |
| 德尔菲法 | 匿名＋多轮＋收敛（区别于头脑风暴的面对面发散） |
| 薪酬三公平 | 内部＝岗位价值评估；外部＝市场调查；个体＝绩效差异 |
| 双因素理论 | 保健因素消不满（工资/条件）；激励因素生满意（成就/认可/成长） |

### 过程/技术/工具（第14-16章）
| 易错点 | 正确记忆 |
|--------|----------|
| DMAIC | 定义→测量→分析→改进→控制 |
| 标准化五法 | 简化、统一化、系列化、通用化、组合化（模块化） |
| 专利期限 | 发明20年、实用新型10年、外观设计15年；**科学发现不授权** |
| 软著 | 开发完成自动产生；自然人终生＋50年 |
| 三类运维工具 | 监控（采集告警）、过程（工单）、自动化（巡检/脚本） |
| 服务台三模式 | 现场、集中、虚拟 |
| 安全库存 | 故障率×补货周期＋服务水平缓冲 |

### 项目管理（第17章）
| 易错点 | 正确记忆 |
|--------|----------|
| 过程组顺序 | 启动→规划→执行→监控→收尾（监控贯穿） |
| 十大领域 | 无"需求管理"（属范围）；有"干系人" |
| 绩效域 | PMBOK7共**8个**（区别于十大领域） |
| CPI/SPI | CPI＝EV/AC，SPI＝EV/PV；＜1均为不利 |
| 风险四策略 | 规避消除、转移（保险外包）、减轻降低、接受（储备） |
| 应急vs管理储备 | 应急针对已识别风险（PM支配）；管理针对未知风险（管理层支配） |
