## 一、九大公式变形考法总表（先看后做）

| 公式 | 原考法 | **变形考法（本卷）** |
|------|--------|---------------------|
| 可用度 | 给 MTBF/MTTR 求可用度 | ①给可用度与停机时长反求 MTTR；②串并联系统可用度估算（并联 1−(1−A)²）；③含维护窗口口径切换 |
| 允许停机 | 给可用度求停机 | ①跨季度口径（Q1=90天）；②"每天/每周"口径换算 |
| 人员配置 | 标准三步 | ①给总人数反求业务量上限；②多技能共享人力（一人跨两岗的折算）；③自动化替代量计算 |
| 流失率 | 期初期末 | ①给流失率反推期初人数；②季度年化 |
| 单位成本 | 总成本/量 | ①多项目间接分摊规则（工时比例）；②边际：增量业务的单位成本变化 |
| 成本利润率 | 利润/成本 | ①给利润率反报价；②投标最低价测算 |
| 风险期望 | P×影响 | ①多风险排序与应对预算分配；②决策树（买不买保险） |
| 挣值 | 四指标 | ①给 EAC 反推 CPI；②TCPI（完工尚需绩效指数）；③剩余工作推演 |
| 关键路径 | 最长路径 | ①求自由时差；②压缩决策（赶工单位成本比较）；③资源受限重排 |

**补充三个进阶公式（本卷新授）**：
1. **系统串联可用度**＝A₁×A₂（串联系统更弱）；**并联可用度**＝1−(1−A₁)(1−A₂)（冗余更强）
2. **TCPI 完工尚需绩效指数**＝(BAC−EV)/(BAC−AC)：剩余预算完成剩余工作的必需效率，＞CPI 说明须比既往表现更好才能按预算完工
3. **自动化替代率**＝(原人力−现人力)/原人力×100%

## 二、计算题审题六步法（贴桌角）

1. 圈出**所有数字与单位**（万/元/小时/分钟/天/月）；
2. 圈出**口径词**：是否剔除维护窗口？储备率基数？班次定义？
3. 写公式→代入→结果三行式；
4. 除不尽：先看选项精度（1位小数？取整方向？）；
5. 结果回代检验（人数×人均≥业务量？）；
6. 最后写**一句管理结论**。
