## 四、备考学习预览器（本地工具）

`备考学习预览器.html` 是单文件零依赖的本地学习工具，**双击用 Chrome / Edge 打开**并载入本文件夹即可：

- **练习模式**：打开综合知识试题自动进入，点选项作答、交卷自动判分、只看错题、一键复制错题摘要
- **考试计时器**：按题型预设 150 / 90 / 120 分钟限时，到点响铃
- **挖空背诵**：隐藏精讲与解析中的加粗要点，点击空白自测
- **划重点**：三色高亮标注、重点本回看与导出
- **全文搜索 / 进度打点 / 学习时长统计 / 深色模式 / 打印试卷**

所有学习数据保存在本机浏览器 localStorage，不依赖网络（首次联网打开后渲染引擎即缓存，可完全离线使用）。

## 五、使用方法

```bash
git clone https://github.com/xiangyu-yang/ruankao.git
cd ruankao
# 双击 备考学习预览器.html（推荐 Chrome/Edge），选择本文件夹载入
```

每日节奏（在职版约 4.5 小时）：精讲 60 分钟 → 限时 150 分钟做 75 题 → 限时 90 分钟案例 → 论文列提纲 → 错题入本。
