## 题库容量

- **综合知识**：30 卷 × 75 题 = **2250 道**单选题（含专业英语题）
- **案例分析**：30 卷 × 3 大题 = **90 道**（含可用度/TCPI/EACt 等计算变形与流程诊断类新题型）
- **论文**：30 卷 × 2 题 ≈ **58 篇**范文（IT 服务全生命周期主线：规划设计→部署实施→服务运营→持续改进→监督验收，含两个素材包与背诵卡体系；Day14/15 为背诵与框架特化日）

## 结构说明

每日五件套（`01-精讲` / `02-试题` / `03-答案与解析` / `04-案例` / `05-论文`）说明见仓库根目录 [README](../README.md)。本目录特点：Day08-10/13/16/22/23/25/28 共八轮全真模拟＋Day17-21/26-27 六个专项卷，题目经过"变形再考"设计（同考点换题干），适合同一考点多角度训练。

## 训练使用建议

- **选择题**：用 `备考学习预览器.html` 练习模式刷题，八轮模拟卷可检验全章掌握度；
- **易混概念**：Day17/18 的"对比记忆对"＋Day27 的 50 组概念对决是本科目记忆负担最重的部分，适合碎片时间反复过；
- **论文素材包**：本目录论文采用"素材包"模式（一个运维服务项目背景适配多主题），背熟素材包后可快速迁移到任意 IT 服务主题；行业背景占用情况见[《00-三科目论文背景行业清单》](../00-三科目论文背景行业清单.md)第三节。
